# BDEImporter

将 BDEngine 静态模型导入服务器。模型在玩家执行命令的位置分批生成，完成后可用 Axiom 编辑。

## 安装

1. 将 `bde-importer-${version}.jar` 放入 `plugins/`，重启服务器。
2. 为操作玩家授予 `bde.spawn`，默认仅 OP 可用。
3. 如需 Axiom 编辑功能，安装匹配的 Axiom 服务端插件和客户端模组，并配置其编辑权限。Axiom 是可选依赖，导入本身不要求安装。

首次启动会生成 `plugins/BDEImporter/config.yml`，默认值与 1.0.1 完全相同。仅支持传统 Paper 调度器，不支持 Folia；插件会拒绝其他
Minecraft 版本。

## 使用

在 BDEngine 中选择 Minecraft **26.3**，通过 **Export to Minecraft Server** 发布并复制六位发布 ID。发布有效期为 10
分钟，过期后需重新发布。详见 [BDEngine 请求说明](https://docs.bde.gg/server-api/reference/request/)。

在目标位置执行 `/bde spawn 123456`，将示例 ID 换成实际发布 ID。等待完成提示后再编辑模型；等待期间可在同一世界内移动。

| 命令                | 用途                               |
|---------------------|------------------------------------|
| `/bde`、`/bde help` | 查看命令帮助                       |
| `/bde spawn <ID>`   | 下载、校验并导入静态模型           |
| `/bde cancel`       | 取消自己的当前导入，清理已生成部分 |

命令只允许具有 `bde.spawn` 权限的玩家执行。`spawn`、`cancel`、`help` 均支持 Tab 补全，不区分大小写；远端发布 ID 不提供候选补全。

模型由一个空的 `block_display`
根实体和展示部件组成，使用原生乘客关系分组。可用 [Axiom 展示实体工具](https://axiomdocs.moulberry.com/contextmenu/displayentities.html)
选择原点节点，整体移动、旋转、缩放或复制。导入完成后，插件不再维护模型；编辑和删除交给 Axiom 等实体工具，`cancel` 不能撤销已完成模型。

## 支持范围

- 读取 `passengers` 中的 `block_display`、`item_display`、`text_display`，保留静态变换、物品和文本数据。一条 SNBT 字符串可包含多个部件。
- 支持 `modelOnly` 和 `full`；`full` 也只导入静态外观，不执行动画、声音或碰撞箱命令。
- 仅保留外观字段和标签，去除 UUID、位置、速度及服务端插件数据；拒绝非展示实体和嵌套 `Passengers`。
- 兼容目标版本为 26.3、但仍使用 `block_state.Name/Properties` 的导出，转换为 `id/properties`。不支持通过手改版本字段导入其他版本的数据。
- 不导入真实方块结构，不安装资源包，不提供缓存、动画引擎或完成后撤销功能。

## 配置与运行限制

编辑 `plugins/BDEImporter/config.yml` 后重启服务器生效，不新增重载命令。所有选项位于 `limits`
下，缺项使用内置默认值，启动时不会自动把缺项写回旧文件。YAML 格式、字段类型或数值无效时，插件报出错误并停用。

| 配置键                   |  默认值 | 含义                                                       |
|--------------------------|--------:|------------------------------------------------------------|
| `response-bytes`         | 1048576 | HTTP 响应字节上限，默认 1 MiB，按实际读取字节计            |
| `parts`                  |     128 | 单模型部件上限，不含额外的 1 个根实体                      |
| `part-bytes`             |    8192 | 单部件规范化 SNBT 的 UTF-8 字节上限                        |
| `model-bytes`            |  131072 | 所有部件规范化 SNBT 的 UTF-8 字节总上限                    |
| `nesting`                |      32 | JSON / SNBT 最大嵌套层数，可设 1～64，限制递归深度         |
| `connect-timeout-millis` |    5000 | 连接超时，毫秒                                             |
| `read-timeout-millis`    |    3000 | 单次阻塞读取超时，毫秒                                     |
| `request-timeout-millis` |   20000 | 下载总时限，毫秒                                           |
| `job-timeout-millis`     |  120000 | 从提交下载到导入完成的时限，毫秒；不限制失败后的清理时长   |
| `cooldown-millis`        |    5000 | 全服请求间隔，毫秒；0 表示不设置冷却                       |
| `step-ticks`             |       2 | 生成与失败清理的调度间隔，每次最多操作一个实体             |
| `chunk-displays`         |     256 | 导入前，区块已有展示实体加本次部件及根实体的上限           |
| `busy-tick-millis`       |    40.0 | 上一 tick 耗时超过此值时暂停生成，不暂停失败清理           |
| `matrix-max-absolute`    |    64.0 | 16 元素变换矩阵中每项允许的最大绝对值                      |
| `view-range`             |     0.5 | 根实体与部件的展示渲染范围系数，实际距离还受客户端设置影响 |

除后三项外均填写整数，范围为 1～2147483639；`cooldown-millis` 允许 0，`nesting` 上限为 64。后三项必须为正的有限数值；
`matrix-max-absolute` 不超过 `Float.MAX_VALUE`，`view-range` 必须处于 `Float.MIN_VALUE`～`Float.MAX_VALUE`，避免转换后成为
0 或无穷大。

各项独立生效。即使 `parts` 允许更多部件，模型也必须满足字节数、深度、矩阵和区块容量限制。调高上限会增加解析、实体生成、禁用清理和客户端负载，建议从默认值开始调整。

全服仍只允许一个导入或清理任务，下载线程与等待队列容量均为一；不自动重试，HTTP 仍只接受 UTF-8、非压缩且不重定向的响应。关闭插值、展示包围盒宽高设为
0 的静态外观规则保持不变。默认设置下，128 个部件在 20 TPS 时约需 13 秒生成。

下载、解析、校验和快照准备在后台线程进行；实体创建、分组和删除在主线程进行。下载总时限在阻塞读取返回后检查，不能中断正在进行的网络读取。

只在原位置已加载且实体数据已加载的区块内生成，并检查世界边界。任务持有区块票据，完成或清理后释放。玩家离线、切换世界、失去权限，或根实体被移动、删除时取消；生成或分组被阻止时也会清理。

正常失败和取消分批清理。插件禁用时立即清理当前未完成任务，已完成模型保留；实体由世界保存。不要用热重载工具卸载插件。

## 开发与验证

使用 JDK 25、Maven 3.9 或更新版本：

```sh
mvn -B verify
```

安装产物为 `target/bde-importer-1.0.2.jar`，已内置并重定位 Adventure NBT。不要安装 `original-*.jar`。Paper API 和 Gson
由服务端提供，无需额外依赖插件。

| 类            | 职责                                         |
|---------------|----------------------------------------------|
| `BdeImporter` | 命令、帮助、补全、异步任务和实体生命周期     |
| `BdeClient`   | 固定地址下载、HTTP 错误和响应读取限制        |
| `ModelParser` | 外部数据校验、SNBT 规范化和外观字段筛选      |
| `Limits`      | 从配置生成不可变限制值，并完成类型、范围校验 |

项目未提供独立公共导入 API。保留插件入口和 Bukkit 覆写方法签名，保留原有命令、权限及模型格式。配置值只在启动时校验一次，以同一个不可变
`Limits` 实例传给下载、解析和主线程任务。ID 在命令入口校验一次，下载器只接收内部传入的 ID
和生成的标签；模型校验集中在解析器，不在生成阶段重复检查类型或渲染参数。
